## UI quality bar
- **M1 starts with `docs/DESIGN.md`** (tokens for color, type, spacing and radius; component states; colorblind-safe status; reduced motion; keyboard controls), approved before any console UI is built.
- From M1 on, every UI task's definition of done covers consistent tokens, every state (loading, empty, error, paused, DNF, 409 stale version, queued offline submit, already played), hover, pressed and disabled feedback, keyboard use, and no overflow at 375px on non-console pages.
- **End of M3: full UI audit.** One read-only auditor per group (consistent design, mobile, every state, real use, before launch). The issue list goes to Rafif for confirmation, then a single fixer applies the fixes, and before/after screenshots are taken at 1440px and 375px.
- **M5:** rerun the "before launch" group (one-line pitch, one primary CTA per page, titles, descriptions, favicons, no placeholder text).

## Environment facts (from planning)
- **Public URL:** `pitwall.rafifdzaky.com` via Cloudflare Tunnel. The rafifdzaky.com DNS must be on Cloudflare.
- **Host:** a new Proxmox VM (Debian) running Docker Compose, joined to the existing tailnet.
- **Deploy:** GitHub Actions → GHCR → Tailscale SSH → `infra/deploy.sh`.
- **Backups:** deferred to M5, since no user data exists before launch.
