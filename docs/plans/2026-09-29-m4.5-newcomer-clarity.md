# M4.5 plan: clear for newcomers

**Spec:** `docs/specs/2026-09-29-m4.5-newcomer-clarity-design.md` (N1–N3). **Execution:** three parallel Sonnet subagents in worktrees, each on its own branch off `feat/m4.5-newcomer`. The lead merges, then runs a fresh review, e2e, the PR, the merge and a deploy watch.

## Workstream A: the objective (N1)
- **Owns:** a new `apps/web/src/os/shell/Objective.tsx` (+ css, + test).
- **Wires it into:**
  - the ack notice copy in `os/shell/noticeFeed.ts` (the "You're on it" entry only);
  - the Monitoring header (`os/apps/monitoring/MonitoringApp.tsx`);
  - the Incident app (`os/apps/tools/IncidentApp.tsx`).
- **Test:** over all `SCENARIOS`, no spoiler word from `INCIDENTS` variants appears in the objective text.

## Workstream B: the legend, the map and the glossary (N2)
- **Owns:**
  - `console/ServiceMap.tsx` (legend, clickable affordance, service count);
  - Monitoring and console CSS;
  - `content/glossary.ts` (new terms);
  - `Term` wrapping in `console/MetricPanel.tsx`, `console/AlertFeed.tsx` and the tool apps' headers and labels (`LogsApp`, `DeploysApp`, `DbApp`).
- **Test:** every `GlossaryId` has an entry; no definition contains a spoiler word from any variant; the map legend and buttons render.

## Workstream C: the next-step guide (N3)
- **Owns:**
  - a new `apps/web/src/os/guide/` (a pure milestone reducer, a hook, and hint texts);
  - the pref `nextStepHints` in `os/prefs.ts` (default on, flag list);
  - the Settings switch (`os/apps/settings/SettingsApp.tsx`);
  - its notice source: add guide notices through `os/shell/noticeFeed.ts`, or its own feed, keeping edits there minimal.
- **Tests:** the reducer; the timing with fake timers; the off switch; none after the first resolved shift; per-variant spoiler check on all hint texts.

## Integration (lead)
- Merge A, B and C, resolving `noticeFeed.ts` if both A and C touched it.
- Run the full unit, typecheck and lint, plus e2e (add `e2e/newcomer.spec.ts`).
- Update the README (the "How to play" objective, the legend) and the roadmap.
- Fresh reviewer (Sonnet), the fix pass, the PR, the merge, and the deploy through `public-smoke`.
- Playbook lessons.
