# M2.5 PR B persona walkthrough: tools and teammates

- **Date:** 2026-09-29
- **Build:** branch `feat/m2.5b-tools`, production web build with the e2e API (Postgres in Docker).
- **Method:** Claude ran a scripted Playwright walkthrough (not a usability test with people). Every persona plays to the end of its path. The incident clock is fast-forwarded with Playwright's clock, and motion is reduced so that the fake clock and the camera do not race. There is a screenshot per step, and console errors are logged.

## Personas

| Persona | Viewport | Path |
|---|---|---|
| Rafif's case | 1440×900 | Ack → selects the loud node (postgres) → Open in DB console → runs the `pg_stat_activity` query → fails over → the chip says "Mitigated · cause still active" → Chat `#deploys` → Open in Deploys on the v142 card → Roll back to v141 → Incident → the cold close |

| A regular | 1440×900 | Chat `#incidents`: `/ask @deployer weather` (a wrong topic) → `/ask @deployer changes` and `/ask @support impact` (two asks at once) → free text in the deployer's DM → `/page @secondary` → Incident's timeline |

## Findings

| # | Grade | What happened | Fix |
|---|---|---|---|
| W1 | Minor | Monitoring's log panel and the Logs window were both regions named "Logs", so a screen reader (and a test) could not tell them apart. | The panel is "Log stream". Console.test pins it. |
| W2 | Minor | Deploys dated the six-day-old v141 "8640 min ago". | Deploy history uses Chat's relative time ("6 d ago"). tools.test pins it. |
| W3 | Minor | The four new dock icons had no colour of their own (grey squircles next to coloured ones). | App colour tokens: logs steel blue, deploys rust, DB console raspberry, incident red (DESIGN.md §2). |
| W4 | Minor | In the DB console, a long command pushed its duration onto two lines ("3" above "s"). | Action durations never wrap. Checked on the screenshot. |

## What worked

- **No console errors** on any path.
- **Rafif's case reads like a real investigation.** The DB console echoed the query and its output (`pg_stat_activity: 98 connections; 90 from checkout-api, 84 of them idle in transaction`). After the failover, the chip read "Mitigated · cause still active". The v142 card in `#deploys` led to Deploys, filtered to checkout-api, with the history and the rollback side by side.
- **At 1366×657**, all four tools fit maximized, with no sideways scrolling.
- **Chat:**
  - A wrong topic stays in the composer as an inline hint ("Ask Bayu about: changes.").
  - Two asks ran at once, and each answered on its own clock (support at 00:20, the deployer at 00:30).
  - Free text got the honest "Not sure what you mean" reply. `/page` showed in the Incident timeline.

## Notes

- **Screenshots of a lazy app** can show "Opening Deploys…" for a moment: the chunk is still loading, as intended.
- **The café whole-run e2e** now runs with reduced motion. The fake clock raced the real-time camera animations: the desktop holds its renders while the camera moves, so the countdown sometimes never showed. `flow.spec.ts` still covers the motion in real time.
