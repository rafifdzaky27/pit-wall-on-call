# Security policy

## Reporting a vulnerability

Please report vulnerabilities **privately** through GitHub:
**Security → Report a vulnerability** on this repository.
Do not open a public issue for security problems.

You can expect an acknowledgement within 72 hours. This is a personal project maintained by one person, so fixes are best-effort, prioritised by severity.

## Scope

- The game at <https://pitwall.rafifdzaky.com> and its API (`/api/*`)
- This repository's code, CI/CD workflows and container images

Out of scope: denial-of-service or volumetric testing, social engineering, and findings in third-party services (Cloudflare, GitHub, Tailscale) that should go to those vendors.

## Supported versions

Only the version currently deployed from `main` is supported.
